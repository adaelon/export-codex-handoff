# Task-aware Compression Frame

**Decision**: Bind every semantic stage to one extractive, evidence-backed Compression Frame.

**Rejected**:
- Segment-local or REDUCE-only focus: MAP can discard evidence before seeing the current objective.
- Mutable per-segment focus: inconsistent policy prevents comparable coverage.
- Free-form goal paraphrase: deterministic validation cannot prove that rewritten scope is supported.

**Critical constraint**: The frame cites source evidence and cannot add unsupported requirements.
**Revisit when**: Compression becomes query-free archival rather than continuation handoff.
**Expanded**: [Evidence-preserving compression slice plan](../slice-plan-evidence-preserving-compression.md#slice-2-compression-frame).
