# Accepted Proposal and Terminal-State Continuation Authority

**Status**: accepted

**Decision**: New Compression Runs bind referential confirmations to the Accepted Proposal and derive a mandatory Terminal-State Claim; stale checkpoints remain historical, while compression-time Git supplies file truth.

**Rejected**:
- Last user utterance alone: confirmations such as `同意，修改这个` lose the proposal they approve.
- Checkpoint as unconditional current authority: a committed or superseded checkpoint can redirect continuation to finished work.
- Cross-field consistency gate: contradictions remain visible evidence and do not block publication by semantic judgment.

**Constraint**: Source termination and compression-time Git are separate observations with separate timestamps; frozen work directories and legacy contracts are never migrated.
**Revisit when**: Codex persists an authoritative task objective and terminal execution snapshot that make transcript-based reconstruction unnecessary.
