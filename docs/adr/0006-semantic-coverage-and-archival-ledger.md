# Semantic Coverage and Archival Ledger

**Decision**: Validate claim-level Semantic Coverage and retain typed operational history.

**Rejected**:
- Turn enumeration as coverage: a complete ID list can accompany an empty summary.
- Category-only REDUCE: decisions and failures lose order, rationale, and supersession.
- LLM self-review: semantic success needs deterministic contract checks and fixtures.

**Critical constraint**: Every summarized turn supports a claim; every ignored turn states why.
**Revisit when**: A stronger native provenance graph subsumes local coverage validation.
